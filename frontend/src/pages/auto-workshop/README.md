## How to build this page
1. Copy `src/pages/luxury-rentals/index.html` into this folder and rename it to `index.html`.
2. Keep the navbar, footer, header/banner structure, and CSS/JS links exactly as they are — do not touch them.
3. In the Fleet dropdown, remove the "active" class from the Luxury & Chauffeur link and add it to your own pillar's link instead.
4. Only replace the middle content sections (title, banner text, images, and the 3 sub-services listed above) with your own pillar's content.
5. Do not create any other files in this repo outside this folder.
